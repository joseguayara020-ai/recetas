Galería de APIs

Proyecto desarrollado durante el Técnico en Programación de Software del SENA.

Objetivo

Desarrollar una aplicación web que permita consumir y mostrar información de diferentes APIs externas de manera dinámica. El proyecto ofrece tres funcionalidades principales: consultar personas aleatorias, buscar recetas de cocina y consultar el clima de diferentes ciudades.

Este proyecto permite practicar el consumo de APIs, el manejo de datos JSON, la programación en PHP y la creación de interfaces web.

Tecnologías

- HTML5: estructura de las páginas web.
- CSS3: diseño, estilos y adaptación visual de la aplicación.
- PHP: procesamiento de información y consumo de APIs.
- cURL: realización de solicitudes HTTP a servicios externos.
- APIs REST: Random User, TheMealDB y Open-Meteo.
- JSON: intercambio y procesamiento de datos.
- Git y GitHub: control de versiones y almacenamiento del proyecto.

Cómo ejecutar

1. Descargar o clonar el repositorio de GitHub.

2. Instalar un servidor local como XAMPP.

3. Copiar la carpeta del proyecto dentro de la carpeta "htdocs".

4. Iniciar Apache desde el panel de XAMPP.

5. Verificar que PHP tenga habilitada la extensión cURL.

6. Abrir el navegador y escribir:
   
   "http://localhost/clase07/"

7. Seleccionar cualquiera de las tres opciones disponibles: Personas, Recetas o Clima.

Nota: Se necesita conexión a Internet para consultar las APIs externas.
